## Pruebas de phyton

1. Asegúrate de tener Python instalado en tu computadora.
2. Descarga el archivo de prueba proporcionado.
3. Abre una terminal o línea de comandos.
4. coloque el archivo `productos_1000.py` en la carpeta donde se ubica el script.
5. Navega hasta la carpeta donde guardaste el archivo.
6. Ejecuta el archivo con el comando: `python products.py`
7. Observa los resultados y verifica que el programa funcione correctamente.
