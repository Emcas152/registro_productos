# DNC

Este proyecto es una aplicación desarrollada en PHP y alojada en un entorno XAMPP.

## Tecnologías

- **Markdown:** Lenguaje de marcado ligero para documentación.
- **PHP:** Lenguaje de programación del lado del servidor.
- **XAMPP:** Paquete que incluye Apache, MySQL y PHP para desarrollo local.
- **MySQL:** Sistema de gestión de bases de datos relacional.

## Requisitos

- PHP 7.x o superior
- XAMPP instalado
- Navegador web

## Instalación

1. Clona o descarga este repositorio en la carpeta `htdocs` de tu instalación de XAMPP:
    ```bash
    git clone <URL-del-repositorio> DNC
    ```
2. Asegúrate de que el servicio de Apache y MySQL estén activos desde el panel de control de XAMPP.

3. Si la aplicación requiere una base de datos:
    - Importa el archivo `.sql` proporcionado en phpMyAdmin.
    - Configura los datos de conexión en el archivo de configuración (por ejemplo, `config.php`).

## Ejecución

1. Abre tu navegador y accede a:
    ```
    http://localhost/DNC/
    ```
2. Sigue las instrucciones en pantalla para utilizar la aplicación.

## Notas

- Consulta la documentación interna para detalles adicionales.
- Si tienes problemas, revisa los permisos de archivos y la configuración de PHP.
